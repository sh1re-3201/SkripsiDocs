6. Build Toolchain & CLI Execution Reference

LuaLaTeX + MiKTeX + Perl

Run these commands inside d:\KULIAH\SkripsiLatek\SkripsiSh1re\SkripsiSh1re in PowerShell (pwsh). Because main.tex uses fontspec with system fonts (Times New Roman and Courier New), lualatex is mandatory. 

# 1. Initial LuaLaTeX pass via latexmk
latexmk -synctex=1 -interaction=nonstopmode -file-line-error -pdf -pdflatex="lualatex %O %S" main

# 2. Generate Daftar Singkatan (acronyms/glossary)
makeglossaries main

# 3. Generate Daftar Pustaka (once .bib file & citations are active)
biber main

# 4. Final LuaLaTeX pass to resolve all TOC, glossary, citations & cross-references
latexmk -synctex=1 -interaction=nonstopmode -file-line-error -pdf -pdflatex="lualatex %O %S" main
